# Pinned to the environment the paper's numbers were produced in.

# These are exact pins, not ranges, on purpose.  The evaluation harness reports
# clustering baselines whose output depends on the scikit-learn version and
# model-quality scores that depend on the pm4py version; kappa itself is pure
# Python and is version-independent.  Running with different versions silently
# shifts every baseline row while leaving the kappa rows byte-identical, which
# is exactly how the published tables and evaluation/results/ drifted apart.
#
# Python 3.13.5.  Reproduce with:
#   python -m venv venv
#   venv/Scripts/python -m pip install -r requirements.txt
#   venv/Scripts/python evaluation/run_evaluation.py --full
